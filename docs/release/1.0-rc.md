# Selis 1.0.0-rc.1 — release-candidate QA

Date: 2026-10-15. Builds: `1.0.0-rc.1` (versionCode 10000010), main + PR #48, **release profile with
the `measure` feature** (minified, optimised Rust, `android:debuggable` false; the feature only
keeps WebView remote debugging on so Maestro and the measurement scripts can read the WebView —
the store build is the same without it, `scripts/check-release-apk.sh`), signed with the local
debug key. Devices: Galaxy S23 (SM-S911B, Android 16, WebView 153) and the AVD
`selis-midrange-api36` (3 GB, Android 16 / API 36). A real mid-range phone is still owed (SPEC P5
gate).

non-debuggable app allows:

| Flow | S23 | AVD | Post-run check on a release build |

| transfer-recover | — | — | **debug-only** flow (needs `debug.selis.*` properties, absent from release builds) |
| transfer-background | — | — | **debug-only** flow (P5b; paces the receive with `debug.selis.receive_kbps`, checks with run-as) |

The debug-only checks verify storage code that is identical in release builds; they passed with
debug builds of the same commit on both devices (19 flows + pages drag each).

## Accessibility

**TalkBack walkthrough: not done.** The S23 is shared with other projects and sessions;
switching TalkBack on there would change how every other session's tests drive it, and a
walkthrough means listening to it. It is on the owner's list (six screens: library, viewer,
annotate, sign, transfer, settings).

What was checked instead, on the S23 release build: the WebView accessibility tree (what TalkBack
reads, `Accessibility.getFullAXTree` over DevTools) of the same six screens — every interactive
node has an accessible name:

| Screen | Interactive nodes | Without a name |
| --- | --- | --- |
| Library | 14 | 0 |
| Viewer | 9 | 0 |
| Annotate | 18 | 0 |
| Sign | 5 | 0 |
| Transfer | 12 | 0 |
| Settings | 14 | 0 |

The page text layer (what TalkBack reads on a page and what copy returns) had stray characters on
every document — an EmbedPDF bug, fixed in this RC (`fix(engine)`, `textruns.node.test.ts`); on
the device the OCR'd document's text layer now has none.

| --neutral-11 on --neutral-3 | secondary text on fills | 6.14 | 7.39 | 6.32 | 4.5:1 |
| --neutral-12 on --surface-raised | text on sheets | 16.46 | 14.65 | 13.97 | 4.5:1 |
| --neutral-11 on --surface-raised | secondary text on sheets | 7.11 | 7.99 | 7.76 | 4.5:1 |

| --accent-contrast on --accent-9 | primary button | 9.23 | 4.69 | 9.53 | 4.5:1 |
| --warning-11 on --neutral-1 | warning text | 5.77 | 11.83 | 5.08 | 4.5:1 |

| --success-11 on --neutral-1 | success text | 6.58 | 10.72 | 5.79 | 4.5:1 |

  unchecked boxes, switch tracks, selectable signature cards, the Library's floating buttons and
  sheet grabbers; dividers and containers keep `--neutral-5/6`.
